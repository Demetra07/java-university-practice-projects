# Java OOP 5-Day Intensive Practice & Architecture Lab

A structured, multi-module Java repository demonstrating daily hands-on implementation of Object-Oriented Programming (OOP) concepts, software design patterns, and core data structures.

##  Repository Structure & Daily Modules

- [x] **`day1_students` — Student Management Subsystem**
  - Focus: Data Encapsulation, State Validation, Constructor Chaining.
  - Features: Basic entity modeling, student registry logic, input verification.

- [x] **`day2_shop` — Retail Product & Discount Model**
  - Focus: Class Inheritance, Method Overriding, Polymorphic Pricing.
  - Features: Hierarchical catalog management, flexible discount strategies, dynamic price calculation.

- [x] **`day3_paymentSystem` — Modular Payment Gateway Engine**
  - Focus: Interface Abstraction, Loose Coupling, Polymorphic Dispatch.
  - Features: Pluggable payment processors (Credit Card, PayPal, Bank Transfer), transaction lifecycle handling.

- [ ] **`day4_module` — Advanced Data Structures & Exception Engine** *(In Active Development)*
  - Focus: Custom Exception Handling, Collections Framework (`HashMap`, `ArrayList`), Defensive Copying.

- [ ] **`day5_module` — Final Capstone Integration & Persistence Layer** *(In Active Development)*
  - Focus: Stream API / I/O File Operations, End-to-End Console Application Integration.

##  Key Technical Concepts Covered

- **Java Standard Edition (JDK 17+)**
- **Core OOP Pillars:** Encapsulation, Inheritance, Polymorphism, Interface Abstraction.
- **Robustness:** Custom Exception Handling & Immutable Invariants.
- **Code Organization:** Modular package boundaries (`day1_*`, `day2_*`, etc.) isolating distinct domain logic.
